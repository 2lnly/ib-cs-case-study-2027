**U-Net** is a [convolutional neural network](https://en.wikipedia.org/wiki/Convolutional_neural_network "Convolutional neural network") that was developed for [image segmentation](https://en.wikipedia.org/wiki/Image_segmentation "Image segmentation").^([\[1\]](#cite_note-Ronneberger_2015-1)) The network is based on a fully [convolutional neural network](https://en.wikipedia.org/wiki/Convolutional_neural_network "Convolutional neural network")^([\[2\]](#cite_note-Shelhamer_2017-2)) whose architecture was modified and extended to work with fewer training images and to yield more precise [segmentation](https://en.wikipedia.org/wiki/Image_segmentation "Image segmentation"). Segmentation of a 512 × 512 image takes less than a second on a modern (2015) [GPU](https://en.wikipedia.org/wiki/Graphics_processing_unit "Graphics processing unit") using the U-Net architecture.^([\[1\]](#cite_note-Ronneberger_2015-1)[\[3\]](#cite_note-3)[\[4\]](#cite_note-4)[\[5\]](#cite_note-5))

The U-Net architecture has also been employed in [diffusion models](https://en.wikipedia.org/wiki/Diffusion_models "Diffusion models") for iterative image denoising.^([\[6\]](#cite_note-6)) This technology underlies many modern image generation models, such as [DALL-E](https://en.wikipedia.org/wiki/DALL-E "DALL-E"), [Midjourney](https://en.wikipedia.org/wiki/Midjourney "Midjourney"), and [Stable Diffusion](https://en.wikipedia.org/wiki/Stable_Diffusion "Stable Diffusion").

U-Net is also being explored for [language models](https://en.wikipedia.org/wiki/Language_models "Language models").^([\[7\]](#cite_note-7)) [Tokenization](https://en.wikipedia.org/wiki/Large_language_model#Tokenization "Large language model") is not a separate step, allowing the model to more easily understand spelling and concurrently [vectorizing](https://en.wikipedia.org/wiki/Vectorization "Vectorization")^(\[*[disambiguation needed](https://en.wikipedia.org/wiki/Wikipedia:WikiProject_Disambiguation/Fixing_links "Wikipedia:WikiProject Disambiguation/Fixing links")*\]) / tokenizing higher level concepts.

## Description

\[[edit](/w/index.php?title=U-Net&action=edit&section=1 "Edit section: Description")\]

The U-Net architecture stems from the so-called "fully convolutional network".^([\[2\]](#cite_note-Shelhamer_2017-2))

The main idea is to supplement a usual contracting network by successive layers, where [pooling](https://en.wikipedia.org/wiki/Pooling_layer "Pooling layer") operations are replaced by [upsampling](https://en.wikipedia.org/wiki/Upsampling "Upsampling") operators. Hence these layers increase the resolution of the output. A successive convolutional layer can then learn to assemble a precise output based on this information.^([\[1\]](#cite_note-Ronneberger_2015-1))

One important modification in U-Net is that there are a large number of feature channels in the upsampling part, which allow the network to propagate context information to higher resolution layers. As a consequence, the expansive path is more or less symmetric to the contracting part, and yields a u-shaped architecture. The network only uses the valid part of each [convolution](https://en.wikipedia.org/wiki/Convolution "Convolution") without any fully connected layers.^([\[2\]](#cite_note-Shelhamer_2017-2)) Therefore, the network can be trained and be run with a mix of input resolutions. To predict the pixels in the border region of the image, the missing context beyond the image boundary is extrapolated by mirroring the input image at the image boundaries. The original U-Net paper further suggested a tiling strategy, where large images are cut into overlapping tiles that are processed independently. This enables processing high-resolution images that would otherwise exceed the available [GPU](https://en.wikipedia.org/wiki/Graphics_processing_unit "Graphics processing unit") memory. Recently, there had also been an interest in receptive field based U-Net models for medical image segmentation.^([\[8\]](#cite_note-8))

## Network architecture

\[[edit](/w/index.php?title=U-Net&action=edit&section=2 "Edit section: Network architecture")\]

The network consists of a contracting path and an expansive path, which gives it the u-shaped architecture. The contracting path is a typical convolutional network that consists of repeated application of [convolutions](https://en.wikipedia.org/wiki/Convolutions "Convolutions"), each followed by a [rectified linear unit](https://en.wikipedia.org/wiki/Rectified_linear_unit "Rectified linear unit") (ReLU) and a [max pooling](https://en.wikipedia.org/wiki/Max_pooling "Max pooling") operation. During the contraction, the spatial information is reduced while feature information is increased. The expansive pathway combines the feature and spatial information through a sequence of up-convolutions and concatenations with high-resolution features from the contracting path.^([\[9\]](#cite_note-9))

## Applications

\[[edit](/w/index.php?title=U-Net&action=edit&section=3 "Edit section: Applications")\]

There are many applications of U-Net in biomedical [image segmentation](https://en.wikipedia.org/wiki/Image_segmentation "Image segmentation"), such as the segmentation of different organs and bodily systems within [computed tomography](https://en.wikipedia.org/wiki/CT_scan "CT scan") (CT) and [magnetic resonance imaging](https://en.wikipedia.org/wiki/Magnetic_resonance_imaging "Magnetic resonance imaging") (MRI) scans. Specific cases include brain image segmentation (''BRATS''^([\[10\]](#cite_note-10))) and liver image segmentation ("siliver07"^([\[11\]](#cite_note-11))) as well as protein binding site prediction.^([\[12\]](#cite_note-Nazem_2021-12)) U-Net implementations have also found use in the physical sciences, for example in the analysis of micrographs of materials.^([\[13\]](#cite_note-13)[\[14\]](#cite_note-14)[\[15\]](#cite_note-15)) Variations of the U-Net have also been applied for medical image reconstruction.^([\[16\]](#cite_note-16)) Here are some variants and applications of U-Net as follows:

1.  Pixel-wise regression using U-Net and its application on pansharpening;^([\[17\]](#cite_note-ref1-17))
2.  3D U-Net: Learning Dense Volumetric Segmentation from Sparse Annotation;^([\[18\]](#cite_note-Çiçek_2016-18))
3.  TernausNet: U-Net with VGG11 Encoder Pre-Trained on ImageNet for Image Segmentation.^([\[19\]](#cite_note-Iglovikov_2018-19))
4.  Image-to-image translation to estimate fluorescent stains ^([\[20\]](#cite_note-20))
5.  In binding site prediction of protein structure.^([\[12\]](#cite_note-Nazem_2021-12))

## History

\[[edit](/w/index.php?title=U-Net&action=edit&section=4 "Edit section: History")\]

U-Net was created by Olaf Ronneberger, Philipp Fischer, [Thomas Brox](https://en.wikipedia.org/wiki/Thomas_Brox "Thomas Brox") in 2015 and reported in the paper "U-Net: Convolutional Networks for Biomedical Image Segmentation".^([\[1\]](#cite_note-Ronneberger_2015-1)) It is an improvement and development of FCN: Evan Shelhamer, Jonathan Long, Trevor Darrell (2014). "Fully convolutional networks for semantic segmentation".^([\[2\]](#cite_note-Shelhamer_2017-2))
